# AxDB 0.3.1

오른쪽 AI 채팅 패널과 쿼리 결과 편집을 추가했습니다. AI는 쿼리를 제안만 하고, 적용과 실행은 사람이 합니다.

## AI 채팅 패널 {new}
- ⌘J로 오른쪽 패널을 엽니다. 패널을 연 채로 편집기와 결과를 계속 쓸 수 있습니다.
- 활성 탭의 쿼리·연결·스키마·선택 영역·최근 오류가 맥락 칩으로 따라옵니다. 행 데이터는 켤 때만 보냅니다.
- `@`로 테이블·컬럼·탭을 멘션하고, `/explain` `/optimize` `/fix-error` 같은 명령을 씁니다.
- SQL 답변마다 **적용 · diff 보기 · 새 탭 · 복사 · .sql 파일 만들기**를 고릅니다. 적용은 ⌘Z 한 번으로 되돌릴 수 있고, 자동 저장과 자동 실행은 하지 않습니다.
- 편집기에서 선택한 부분을 ⌘L로 패널에 보냅니다.
- 여러 파일 변경 제안은 파일별로 수락·거절하고 되돌릴 수 있습니다.

## 권한·모델 선택 {improved}
- 입력창의 권한 칩에서 **읽기 전용 / 승인 후 쓰기**를 고릅니다. 읽기 전용 연결에서는 쓰기를 고를 수 없습니다.
- 모델과 Effort를 입력창 아래 메뉴에서 바로 바꿉니다.
- AI가 쿼리 실행이나 MCP 도구를 제안하면 승인 카드가 뜹니다. DELETE·DROP 같은 파괴적 작업은 허용을 누른 뒤 4초 안에 취소할 수 있습니다.

## 쿼리 결과 편집 {new}
- PostgreSQL, MySQL·MariaDB, SQLite에서 테이블 하나를 조회하고 기본 키가 들어 있는 결과를 바로 편집합니다. MongoDB는 find 결과를 문서 단위로 편집합니다.
- 저장은 변경 미리보기 → 승인 → 실행 순서입니다. 그사이 다른 곳에서 같은 행이 바뀌었으면 롤백하고 알려 줍니다.
- JOIN·집계·계산 컬럼 결과는 읽기 전용이고, 편집할 수 없는 이유를 보여 줍니다.

## 다듬은 곳 {improved}
- 실제 연결할 때도 DNS → SSH → TLS → 인증 → 권한 단계를 보여 줍니다.
- 작업공간 검색(⌘K)의 아이콘·분류·단축키 표시를 정리했습니다.
- AI 설정 저장 시 결과를 바로 보여 줍니다.

## 고친 문제 {fixed}
- AI 패널 제목이 잘려 보이던 문제
- 연결 진행 팝업의 여백·정렬
