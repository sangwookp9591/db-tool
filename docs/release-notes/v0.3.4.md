# AxDB 0.3.4

실행 계획을 읽은 뒤 연결이 끊기던 문제와 AI 스키마 맥락 시간 초과를 고치고, 실행 이력 검색과 SQL 메모를 추가했습니다. 에디터·AI 패널·워크벤치 화면도 하나의 컴포넌트 체계로 정리했습니다.

## 실행 이력과 SQL 메모 {new}
- 이전에 실행한 SQL을 검색합니다. 한국어와 식별자의 중간 글자도 찾고, 연결·결과·종류로 걸러낼 수 있습니다.
- 자주 쓰는 SQL을 제목·태그와 함께 메모로 저장하고, 편집기에 넣거나 새 탭으로 열 수 있습니다. 쿼리 탭의 "메모로 저장"으로 선택 영역이나 전체 쿼리를 바로 저장합니다.
- 단축키 Cmd/Ctrl+Shift+H로 이력 검색을 엽니다. 목록은 보이는 줄만 그려서 많은 이력에서도 가볍게 동작하고, 패널은 처음 열 때만 불러옵니다.
- 이력 저장 방식을 바꿨습니다. 쿼리를 실행할 때마다 이력 파일 전체를 다시 쓰던 방식에서 내장 SQLite 저장소로 옮겨, 기록은 한 건씩 추가합니다. 보관 기본값은 최근 50,000건·180일입니다(이전에는 1,000건).
- 기존 `history.jsonl`은 처음 실행할 때 자동으로 옮기고, 원본은 `history.jsonl.migrated`로 남깁니다. 손상된 줄은 건너뜁니다. 비밀값 마스킹은 그대로 적용합니다.

## 실행 계획과 연결 안정성 {fixed}
- 실행 계획을 읽은 뒤 "드라이버 연결이 끊겼습니다"가 표시되거나 연결이 계속 도는 문제를 고쳤습니다. 취소 요청을 보내지 못해도 정상 연결을 끊지 않습니다.
- 한 요청의 취소가 늦어질 때 같은 드라이버를 쓰는 다른 연결까지 종료되던 문제를 고쳤습니다. 드라이버가 응답하는지 확인한 뒤에만 종료합니다.
- 편집할 때마다 자동으로 데이터베이스에서 실행 계획을 확인하던 동작을 없앴습니다. 입력 중 불필요한 DB 작업과 화면 흔들림이 줄었습니다. 이에 따라 입력 중 자동 진단은 더 이상 "대형 테이블 전체 스캔" 경고를 내지 않습니다. 이 경고는 "실행 계획 읽기" 결과에서 그대로 확인할 수 있습니다.
- 편집기의 진단 밑줄이 글자를 입력하거나 지울 때 해당 글자를 따라 이동합니다. 문서가 짧아질 때 편집기 오류가 나던 문제를 막았습니다.
- 실행 계획을 다시 요청하면 이전 요청의 결과가 화면을 덮어쓰지 않습니다.

## AI 스키마 맥락 {fixed}
- 테이블이 많은 데이터베이스에서 "Schema context timed out"이 나던 문제를 고쳤습니다. PostgreSQL과 MySQL/MariaDB가 테이블마다 컬럼을 따로 조회하던 것을 스키마 단위 한 번의 조회로 줄였습니다.
- 스키마 맥락을 60초 동안 다시 쓰고, 같은 정보를 반복해서 읽지 않습니다. 시간이 초과돼도 모은 만큼으로 응답하고 일부만 포함했다는 표시를 남깁니다.
- 스키마를 읽는 동안 세션 잠금을 오래 잡아 다른 쿼리를 막던 문제를 줄였습니다.

## 화면 정리 {improved}
- AI 채팅의 오류 표시를 정리했습니다. 오류에는 오류 아이콘과 한국어 안내를 보여주고, 원문은 접어 두며, "다시 시도"를 제공합니다. 말풍선·맥락 칩·입력창의 간격과 정렬도 맞췄습니다.
- 연결 앱 화면에서 상태 표시가 이름과 겹치고 로고가 상자 밖으로 넘치던 문제, "연결 해제" 버튼의 이중 테두리를 고쳤습니다.
- 워크벤치의 선택 목록과 파일 선택을 하나의 공통 컴포넌트로 통일했습니다. 파일 선택은 한국어로 표시하고 드래그해서 놓을 수 있습니다.
- 편집기와 다이얼로그의 테두리, 연결 카드에서 마우스를 올렸을 때 포인터를 따라 움직이던 그라디언트 효과를 없앴습니다. 이제 평평한 호버 색과 포커스 테두리만 표시하고, 포인터 이동마다 하던 계산도 사라졌습니다. 브랜드 버튼도 그라디언트 대신 단색입니다.
- 로딩 중에 반복해서 흐르던 반짝임(로딩 버튼, AI "생각 중" 표시, 드라이버 스켈레톤, 첫 화면 로고)을 없앴습니다. 이 효과들은 화면이 바뀌지 않아도 계속 다시 그려졌습니다. 주 버튼의 그라디언트와 그림자도 단색으로 바꿨습니다.
- 앱 전체에서 11px보다 작던 글자(9~10px, 96곳)를 11px로 키웠습니다. 연결 카드의 종류별 연한 색 상자는 없앴습니다.
- 쿼리 화면에서 "패널에 묻기"를 도구 줄로 옮겨 에디터가 한 줄만큼 위로 올라왔고, 결과 도구 줄의 편집·내보내기·보기 전환이 오른쪽에 한 묶음으로 정렬됩니다. 이력 패널을 열어도 결과 표가 패널과 겹치지 않습니다.
- 쿼리 화면과 빈 작업공간에 화면 제목(h1)을 두어 스크린 리더가 화면을 구분할 수 있습니다.

## 내부 품질 {neutral}
