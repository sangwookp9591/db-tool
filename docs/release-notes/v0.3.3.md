# AxDB 0.3.3

데이터베이스 연결부터 탐색·편집까지의 흐름을 개선하고, 사용자·권한 관리와 MCP 에이전트 연결 안내를 정리했습니다.

## DB 탐색과 SQL 자동완성 {fixed}
- 연결 후 스키마 안의 테이블·뷰 목록이 자동으로 표시되도록 고쳤습니다.
- SQL 편집기에서 실제 연결의 테이블 이름을 자동완성합니다. 여러 스키마와 인용이 필요한 이름도 처리합니다.
- 연결을 바꾸거나 해제한 뒤 이전 탐색 요청이 현재 목록을 덮어쓰는 문제를 고쳤습니다.

## 연결 추가·편집 {improved}
- 필수 입력이 빠진 경우 해당 단계로 이동하고, 연결 테스트 오류를 폼 안에서 확인할 수 있습니다.
- 드라이버 변경 시 이전 입력과 테스트 결과를 정리합니다.
- SSH·프록시의 새 비밀번호를 저장 전에 테스트할 수 있습니다. 붙여넣기·테스트·취소 중에는 비밀값을 저장하지 않습니다.

## 메뉴와 체크박스 {fixed}
- 연결 메뉴와 탐색기 우클릭 메뉴가 스크롤 영역이나 창 가장자리에서 가려지는 문제를 고쳤습니다.
- 메뉴의 키보드 이동, Escape로 닫기, 포커스 복원을 개선했습니다.
- 긴 선택 목록에서 클릭한 항목과 실제 선택 결과가 달라지는 문제를 고쳤습니다.
- 연결 진행 안내가 설정 메뉴를 가리는 문제와 MCP 체크박스의 표시·클릭 영역 정렬을 고쳤습니다.

## 사용자·권한 관리 {improved}
- 사용자·역할 선택, 스키마·객체 검색, 페이지별 권한 조회를 제공합니다.
- PostgreSQL에서 전체 권한 표가 50,000셀을 초과해 조회에 실패하는 문제를 고쳤습니다. 이 기능에는 같은 버전의 PostgreSQL 드라이버가 필요합니다.
- 여러 페이지에서 작성한 변경 계획을 유지하고, 미리보기와 승인 후 적용합니다. 읽기 전용 연결에서는 변경을 제한합니다.
- 워크벤치 탭을 화면 너비에 맞춰 배치하고, 적용하지 않은 변경 계획을 버리는 이동에 확인을 추가했습니다.

## MCP 에이전트 연결 {new}
- 클라이언트마다 연결 방법을 열어 Codex·Claude Code 등록 명령을 복사할 수 있습니다.
- Codex TOML과 일반 MCP JSON 설정을 복사할 수 있습니다.
- 허용 도구를 한국어 이름과 기술 ID로 표시하고, 브리지 준비 상태와 실제 요청 기록을 구분합니다.
- 토큰 입력·재발급과 변경된 브리지 주소를 다시 등록하는 절차를 안내합니다.
