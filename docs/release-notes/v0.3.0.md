# AxDB 0.3.0

AI와 함께 일하는 DB 워크벤치로 확장했습니다. 의도를 말하면 AI가 계획을 만들고, 사람은 미리보기로 확인한 뒤 승인합니다. AI는 직접 실행하지 않습니다.

## MySQL·MariaDB 드라이버 {new}
- MySQL 8과 MariaDB 11을 설치형 드라이버로 지원합니다.
- 스키마 탐색, SQL 실행과 취소, ERD, 표 편집 미리보기, 실행 계획, 백업, 권한 조회를 지원합니다. DDL은 MySQL 특성상 바로 커밋되므로 미리보기 대신 경고를 보여 줍니다.
- 앱 업데이트 없이 드라이버 화면에서 설치합니다.

## 연결: SSH·프록시·클라우드 IAM {new}
- SSH 터널(키, ssh-agent, 비밀번호, 점프 호스트)과 SOCKS5·HTTP 프록시로 연결합니다. 처음 접속하는 서버는 지문을 확인하고, 지문이 바뀌면 연결을 막습니다.
- AWS RDS·Aurora와 GCP Cloud SQL의 IAM 인증을 지원합니다.
- 연결 문자열, JDBC URL, psql 명령, `~/.ssh/config` 호스트를 붙여 넣으면 칸이 자동으로 채워집니다.
- 연결 테스트가 DNS → SSH → TLS → DB 인증 → 권한 확인을 단계별로 보여 주고, 실패하면 원인과 해결 방법을 안내합니다.

## 편집기: 실행 계획·위험 경고·리팩터링 {new}
- 결과 옆 **계획** 탭에서 실행 계획을 트리와 비용 막대로 보여 주고, 가장 비싼 단계와 예상·실제 행 수 차이를 강조합니다.
- WHERE 없는 UPDATE·DELETE, 큰 테이블 전체 스캔 같은 위험한 쿼리를 입력 중에 경고합니다.
- 서식 정리, `SELECT *` 펼치기, 별칭 이름 바꾸기, 하위 쿼리를 CTE로 추출하기를 지원합니다.

## 관리: 가져오기·스키마 비교·마이그레이션·백업·권한 {new}
- CSV·JSON·NDJSON·XLSX 파일을 끌어다 놓고 컬럼을 매핑해 미리 본 뒤 한 번에 가져옵니다.
- 두 연결의 스키마를 비교해 마이그레이션 DDL을 만들고, 위험한 변경을 표시합니다.
- 마이그레이션 폴더(Flyway, Prisma, 번호 SQL)의 적용·대기 상태를 보여 줍니다.
- 외부 프로그램 없이 백업하고 새 DB로 복원합니다. 큰 DB도 스트리밍으로 처리합니다.
- 역할·권한을 표로 보고, GRANT·REVOKE 계획을 미리 본 뒤 적용합니다.

## AI 계정과 MCP {new}
- Claude 로그인, ChatGPT 로그인, API 키로 앱 안에서 AI를 씁니다. 모델과 Effort를 고를 수 있습니다.
- 자연어로 말하면 AI가 작업 계획을 만듭니다. 행 데이터와 비밀값은 AI에 보내지 않습니다.
- MCP 연결 화면을 새로 만들었습니다. 클라이언트별 권한을 편집하고, 연결과 해제를 같은 곳에서 합니다.

## 더 가볍고 빠르게 {improved}
- 첫 화면이 읽는 JavaScript를 gzip 기준 약 69KB에서 26KB로 줄였습니다. 나머지 기능은 쓸 때 불러옵니다.
- 큰 결과를 바이너리 열 형식으로 전송해, 결과 탭을 모두 닫은 뒤 남는 메모리를 약 125MiB 줄였습니다.
- 쓰지 않는 드라이버 프로세스는 5분 뒤 자동으로 종료합니다.

## 화면 개선 {improved}
- 드라이버 화면을 실제 DB 로고 타일과 상태 배지(설치, 진행, 완료, 업데이트, 실패)로 바꿨습니다.
- 변경 기록을 타임라인으로 보여 주는 **새로운 기능** 화면을 추가했습니다.
- 모든 연결에 해제 버튼을 두었고, GitHub ⭐ 안내를 추가했습니다.

## 설치 {improved}

- Windows: `AxDB_0.3.0_x64-setup.exe`. 처음 실행할 때 SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.
