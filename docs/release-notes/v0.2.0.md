# AxDB 0.2.0

필요한 데이터베이스 드라이버만 골라 설치하는 구조로 바뀌었습니다. 앱 자동 업데이트, 첫 실행 안내, 결과 내보내기도 추가했습니다.

## 설치형 드라이버
- 앱에는 드라이버가 들어 있지 않습니다. **드라이버** 화면이나 첫 실행 안내에서 PostgreSQL, Neo4j, SQLite, MongoDB, Redis 중 필요한 것만 설치하세요.
- 설치할 때 공식 서명과 SHA-256을 검증합니다. 서명이 확인되지 않는 `.axdriver` 파일은 경고를 확인하고 동의해야 설치됩니다.
- 진행 상황을 단계별(다운로드 → 검증 → 서명 확인 → 설치 → 연결 확인)로 보여 주고, 설치 중 취소하거나 실패하면 다시 시도할 수 있습니다.
- 드라이버는 별도 프로세스로 실행됩니다. 드라이버가 비정상 종료되어도 앱은 계속 동작하고, 드라이버는 다음 요청 때 다시 시작됩니다.
- 큰 결과는 받는 즉시 표에 표시합니다. 10만 행 기준으로 내장 방식과 비교해 첫 행은 +1%, 전체 완료는 +12% 차이입니다.

## 앱 업데이트
- 새 버전이 나오면 상태바에 업데이트 배지가 나타납니다. 릴리스 노트를 확인한 뒤 바로 업데이트하고 다시 시작할 수 있습니다.
- 설정에서 업데이트 자동 확인을 끄거나 특정 버전을 건너뛸 수 있습니다. 업데이트 파일은 서명을 검증한 뒤 설치합니다.

## 처음 사용하기
- 첫 실행 때 7장면 안내가 나옵니다. 드라이버 설치, 연결과 탐색, ERD와 뷰어, 권한과 읽기 전용, MCP 연결, 내보내기와 AI 사용법을 다룹니다. 메뉴에서 다시 볼 수 있습니다.

## 내보내기
- 결과를 CSV(Excel 호환), JSON(큰 정수 보존), Markdown, NDJSON 형식으로 저장할 수 있습니다.
- ERD와 그래프는 SVG나 PNG 이미지로 저장할 수 있습니다.

## 화면 개선
- 사이드바의 연결과 탐색기를 각각 접고 펼 수 있고, 둘 사이 높이를 조절할 수 있습니다. 컴팩트 보기도 추가했습니다.
- MCP 연결 화면에서 스크롤하면 위로 튀던 문제를 고쳤습니다.
- 화면 요소가 텍스트로 선택되어 회색 박스가 생기던 문제를 고쳤습니다.

## 설치
- macOS(Apple Silicon·Intel): `AxDB_0.2.0_universal.dmg`. Apple 공증을 받았습니다.
- Windows: `AxDB_0.2.0_x64-setup.exe`. 코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.
