# V1 작업 결과

main `480eeac`의 0.3.0을 별도 debug 앱과 테스트 DB로 검증했다. 실제 앱 E2E는 21+5+13개, Rust 실DB 검사는 303개, UI 검사는 146개가 통과했고 tsc·clippy도 통과했다. native 캡처 35장과 마스킹한 원자료를 남겼다.

MCP 합산 행 상한 누락, 변경 로그의 현재 버전, native CSP에 막힌 인라인 드라이버 이미지를 작게 수정했다. 숨김 상태 15초 동안 Mongo 드라이버 CPU가 0.01초 증가해 엄격한 CPU 0 조건은 실패로 남겼다. 표시 상태 CPU와 표시/숨김 running 애니메이션은 모두 0이었다.

AI 실호출·OAuth·실제 OS 키체인·클라우드 IAM·배포 업데이트 설치는 미검증이다. 사용자 앱과 데이터는 건드리지 않았고 commit/push는 하지 않았다. 항목별 결과·환경·증거 범위는 [V1_NATIVE_030.md](V1_NATIVE_030.md)에 있다.
